# arclip for Homebrew

[arclip](https://arclip.design/cli) builds and checks ARClip projects from a terminal, CI or an AI agent.

```sh
brew install webar-studio/tap/arclip
arclip login
```

macOS 13+ (Apple Silicon and Intel) and Linux (x64 and ARM64). Updates arrive with `brew upgrade`.

The formula is written by the arclip release on every version; changes made here by hand are overwritten.
Other ways to install: https://arclip.design/cli/releases
